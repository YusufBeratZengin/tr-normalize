# Security Policy

`tr-normalize` is a pure-Python text library with no runtime dependencies. It makes no network
requests, runs no subprocesses and writes no files; the CLI only reads standard input or its
arguments and writes to standard output.

## Supported versions

Only the latest released version receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report privately through GitHub security advisories:

<https://github.com/YusufBeratZengin/tr-normalize/security/advisories/new>

Include the affected version, a minimal input that reproduces the problem (for example a
pathological string that causes excessive run time) and the impact. Do not include real personal
data. You can expect an acknowledgement within one week.
